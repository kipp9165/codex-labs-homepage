# Codex OS Runtime Service v1

This service exposes Codex OS as a cloud API.

## Endpoints

- `/os_boot`
- `/os_shutdown`
- `/os_runtime`
- `/os_runtime_shutdown`
- `/os_distribution`
- `/os_distribution_shutdown`
- `/os_finalize`
- `/os_finalize_shutdown`
- `/os_complete`
- `/os_complete_shutdown`

Codex OS Runtime Service v1 is the official cloud execution layer for Codex OS.
