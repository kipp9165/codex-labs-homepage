Protocol Classes

Boundary Protocols

  • Define what may enter, mutate, or traverse a sovereign surface.
  • Protect public, founder, and whale-facing structures from unauthorized state change.
  • Keep execution boundaries explicit across all phases.

Drift Protocols

  • Detect divergence between canonical intent and live system behavior.
  • Prevent silent copy, logic, or state mutation across synchronized surfaces.
  • Preserve consistent language and deterministic output under load.

Continuity Protocols

  • Maintain identity persistence across runtime, finalization, launch, and stabilization.
  • Carry governed state through each operating transition without fragmentation.
  • Ensure each surface resolves back to the same sovereign source of truth.

Governance Protocols

  • Authorize only approved changes and execution paths.
  • Bind operator action to explicit mandates and deterministic review cycles.
  • Lock the system against non-governed behavior on internal and public surfaces.
