# Scroll Minting Protocol

Scroll minting is the process of converting lived operational knowledge into reusable artifacts. This protocol ensures each scroll is precise, testable, and transferable. Use it when codifying practices that must survive scale.

## Source Capture
- Gather real decisions, failures, and recoveries.
- Prioritize evidence from repeated scenarios.
- Exclude abstract advice without operational proof.

## Scope Definition
- Define audience, context, and failure mode.
- State what the scroll will and will not cover.
- Keep scope tight enough to execute reliably.

## Protocol Drafting
- Write steps in action sequence order.
- Add thresholds, triggers, and stop conditions.
- Remove ambiguous verbs and vague timing.

## Integrity Review
- Validate with operators who run the work.
- Stress-test for edge cases and misuse.
- Resolve contradictions before release.

## Mint and Version
- Publish with version number and owner.
- Record effective date and review schedule.
- Archive previous versions for traceability.

## Adoption Loop
- Train teams using live scenarios.
- Track adherence and outcome quality.
- Refine protocol based on observed friction.
