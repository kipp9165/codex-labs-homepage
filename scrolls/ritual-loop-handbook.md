# Ritual Loop Handbook

Ritual loops convert good intentions into stable behavior. This handbook defines cadence, trigger, action, and review so performance remains consistent. Use it to prevent teams from restarting discipline every week.

## Loop Architecture
- Define trigger, routine, and completion signal.
- Keep loop scope narrow and repeatable.
- Attach one measurable outcome per loop.

## Daily Rituals
- Start with a short alignment pass.
- End with unresolved blocker capture.
- Keep rituals operational, not performative.

## Weekly Rituals
- Review commitments versus completions.
- Surface structural blockers, not personal blame.
- Recommit priorities for the next cycle.

## Exception Handling
- Create fallback rituals for disrupted days.
- Log skipped loops with reason codes.
- Resume normal cadence without redesign.

## Enforcement Protocol
- Assign loop stewards for each team.
- Escalate repeated misses to operating leads.
- Reward consistency over heroic bursts.

## Loop Evolution
- Retire loops that no longer produce value.
- Merge duplicate rituals that compete for attention.
- Version loop definitions after each quarter.
