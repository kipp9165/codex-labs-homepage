# Modern SEO Playbook

This playbook defines SEO as systems behavior, not keyword theater. It aligns structure, intent, and publishing rhythm so discovery becomes predictable. Use it to convert scattered pages into a coherent search surface.

## Search Intent Mapping
- Classify every page by primary intent: navigate, compare, act, or learn.
- Set one core query family per page.
- Remove overlapping intent between sibling pages.

## Crawl Path Design
- Keep URL paths stable and human-readable.
- Ensure each page is reachable in two to three clicks.
- Minimize dead-end pages without contextual exits.

## Metadata Discipline
- Write one precise title and one precise description per page.
- Reflect real page promise, not broad marketing claims.
- Keep metadata aligned with on-page headings.

## Topical Cluster Architecture
- Group pages into clear thematic clusters.
- Assign one cluster steward for consistency.
- Define canonical page for each cluster topic.

## Publishing Cadence Control
- Ship updates in predictable cycles.
- Track which updates improve qualified impressions.
- Retire stale pages instead of endlessly patching them.

## Measurement and Correction
- Monitor index coverage, query fit, and click quality.
- Investigate drops by cluster, not by isolated page.
- Run monthly correction loops with explicit owners.
