# Multi Surface Distribution Manual

Distribution fails when message, format, and audience are misaligned across surfaces. This manual defines a structural approach to publishing without fragmenting voice. Use it to keep every surface coherent while adapting execution.

## Surface Inventory
- List all active distribution surfaces.
- Define each surface's role in the funnel.
- Retire surfaces with no strategic function.

## Core Message Spine
- Create one canonical message per campaign.
- Derive surface variants from the same spine.
- Prevent contradictory claims across channels.

## Format Translation
- Map message to native format per surface.
- Preserve intent while changing delivery style.
- Keep call-to-action consistent by objective.

## Cadence Matrix
- Define frequency rules for each surface.
- Sequence releases to reinforce, not collide.
- Reserve capacity for real-time adjustments.

## Performance Reading
- Compare outcomes by objective, not vanity reach.
- Track conversion quality by surface origin.
- Identify surfaces that dilute qualified traffic.

## Distribution Governance
- Assign owners per surface and campaign.
- Enforce pre-publish alignment checks.
- Run post-cycle reviews and consolidate learnings.
