# Commission Blueprint

This blueprint defines how a Codex Commission moves from diagnosis to structural intervention. It keeps scope precise while preserving room for bespoke architecture. Use it to ensure every commission produces durable operational change.

## Intake Framing
- Capture the structural problem in one sentence.
- Identify affected layer: team, workflow, system, or decision.
- Define desired state in observable terms.

## Diagnostic Sweep
- Review current process maps and failure points.
- Interview key operators for hidden constraints.
- Validate root causes before drafting solutions.

## Intervention Design
- Select artifact type: scroll, pack, or substrate work.
- Define architecture boundaries and interfaces.
- Set success criteria before build begins.

## Build and Alignment
- Draft protocols with role-based clarity.
- Run alignment sessions with operating owners.
- Resolve adoption blockers before handoff.

## Deployment Protocol
- Launch with phased rollout when risk is high.
- Provide execution checklists and escalation paths.
- Monitor early behavior for divergence.

## Continuity Layer
- Schedule post-deployment review windows.
- Capture lessons into versioned artifacts.
- Define ongoing stewardship responsibilities.
