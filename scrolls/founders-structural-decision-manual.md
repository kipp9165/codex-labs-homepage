# Founders Structural Decision Manual

This manual turns high-pressure decisions into repeatable structure. It separates signal from urgency so founders can decide without drift. Use it whenever ambiguity is rising faster than organizational clarity.

## Decision Classing
- Label decisions as reversible, constrained, or terminal.
- Assign required rigor by class.
- Avoid terminal framing for reversible calls.

## Constraint Framing
- Define budget, time, and risk boundaries first.
- Record non-negotiables before options are discussed.
- Reject options that violate core constraints.

## Option Construction
- Build three viable paths with clear tradeoffs.
- Require downside statements for each path.
- Eliminate options that depend on hope alone.

## Evidence Thresholds
- Set minimum evidence needed to decide.
- Distinguish facts, assumptions, and unknowns.
- Time-box evidence gathering to prevent paralysis.

## Decision Ritual
- Name decider, challengers, and recorder.
- Run a fixed sequence: propose, challenge, decide, log.
- Close with explicit next actions and owners.

## Post-Decision Integrity
- Audit outcomes against declared assumptions.
- Capture lessons without rewriting history.
- Update decision rules based on observed failures.
