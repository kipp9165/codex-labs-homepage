# Zombie Systems Diagnostic Scroll

Zombie systems consume resources without producing meaningful outcomes. This diagnostic scroll identifies these systems and defines shutdown or rehabilitation paths. Use it when operations feel heavy, slow, and directionless.

## Zombie System Signals
- High maintenance burden with low strategic output.
- Frequent exceptions and manual patches.
- Ownership ambiguity across critical functions.

## Dependency Audit
- Map upstream and downstream dependencies.
- Identify what breaks if the system is removed.
- Separate real dependencies from assumed dependencies.

## Value Verification
- Measure current contribution against cost.
- Confirm whether outcomes are still required.
- Flag systems preserved only by habit.

## Rehabilitation Decision
- Choose repair, replace, contain, or retire.
- Estimate transition risk for each path.
- Select the path with highest long-term integrity.

## Execution Plan
- Define timeline, owners, and rollback logic.
- Communicate impact windows clearly.
- Track transition completion by milestone.

## Post Mortem and Guardrails
- Record why the system became a zombie.
- Add early-warning indicators to governance loops.
- Prevent reintroduction of equivalent structural debt.
