# Semantic Cluster Playbook

Semantic clusters organize content so search engines and users can understand domain authority. This playbook aligns topic architecture with real user questions and business intent. Use it to build discoverability without content sprawl.

## Cluster Definition
- Define each cluster by user problem, not product slogan.
- Assign one pillar page and supporting pages.
- Keep cluster boundaries explicit.

## Query Family Mapping
- Group related queries by intent stage.
- Map each family to one primary page.
- Prevent multiple pages from targeting identical query sets.

## Internal Context Weaving
- Link support pages to the cluster pillar naturally.
- Use consistent terminology across the cluster.
- Remove orphan pages that break semantic continuity.

## Content Depth Control
- Expand where user decision risk is high.
- Keep low-risk topics concise and direct.
- Replace repetitive pages with consolidated assets.

## Cluster Health Metrics
- Track impressions, click quality, and rank spread by cluster.
- Monitor cannibalization signals monthly.
- Compare cluster growth to publishing input.

## Iteration Protocol
- Refresh cluster maps each quarter.
- Retire weak pages and strengthen high-signal nodes.
- Preserve naming consistency through updates.
