# Codex OS v2.0 - Governance v20-v23 Specification

## Overview
Governance v20-v23 expands Codex OS governance into constitutional reasoning, authority modeling, legitimacy forecasting, and multi-surface arbitration.

## Governance v20 - Constitutional Intent
Defines the constitutional intent behind actions.
Fields:
- intent_origin
- intent_domain
- intent_authority
- intent_legitimacy

## Governance v21 - Authority Gradient
Models authority flow across domains.
Fields:
- authority_source
- authority_vector
- authority_slope
- authority_confidence

## Governance v22 - Legitimacy Continuum
Tracks legitimacy across time, drift, replay, and arbitration.
Fields:
- legitimacy_score
- legitimacy_decay
- legitimacy_horizon
- legitimacy_confidence

## Governance v23 - Cross-Constitutional Arbitration
Resolves governance across multiple constitutional surfaces.
Fields:
- arbitration_surface
- arbitration_conflict
- arbitration_resolution
- arbitration_legitimacy

## Integration Notes
- All v20-v23 fields are optional for v1.x compatibility.
- Arbitration requires authority gradient and legitimacy continuum fields.
- Intent fields enhance drift forecasting.
