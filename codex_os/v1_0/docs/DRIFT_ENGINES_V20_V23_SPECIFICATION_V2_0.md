# Codex OS v2.0 - Drift Engines v20-v23 Specification

## Overview
Drift Engines v20-v23 expand drift analysis into constitutional, authority, temporal, and legitimacy surfaces.

## Drift v20 - Temporal Entropy
Measures constitutional uncertainty over time.
Fields:
- entropy_rate
- entropy_vector
- entropy_confidence

## Drift v21 - Constitutional Drift
Measures divergence between constitutional intent and runtime execution.
Fields:
- intent_alignment
- execution_alignment
- constitutional_delta

## Drift v22 - Authority Drift
Measures changes in authority gradients across domains.
Fields:
- authority_delta
- authority_slope_shift
- authority_confidence_delta

## Drift v23 - Legitimacy Drift
Measures legitimacy decay across time, replay, and arbitration.
Fields:
- legitimacy_delta
- legitimacy_horizon_shift
- legitimacy_confidence_delta

## Integration Notes
- Drift v20-v23 fields enhance governance v20-v23.
- Drift v23 requires legitimacy continuum fields.
- Drift v21 requires constitutional intent fields.
