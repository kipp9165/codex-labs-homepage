# Codex OS v1.x -> v2.0 Migration Guide

## Overview
This guide explains how to migrate from Codex OS v1.x to Codex OS v2.0.

## 1. Constitutional Substrate
No breaking changes.
v2.0 adds constitutional inference but retains all v1.x primitives.

## 2. Governance
v1.x: Governance v1-v10
v2.0: Governance v20-v23

Migration:
- Existing governance rules remain valid
- New constitutional intent fields optional
- Arbitration layer additive

## 3. Drift Engines
v1.x: Drift v1-v11
v2.0: Drift v20-v23

Migration:
- Drift scoring remains compatible
- New temporal entropy fields optional

## 4. Autonomous Runtime
v2.0 adds constitutional bundles and fallback routes.
Existing runtime actions remain valid.

## 5. Simulation Layer
v2.0 adds constitutional simulation tier.
All v1.x tiers remain unchanged.

## 6. Commerce Layer
v2.0 adds constitutional pricing and registry.
v1.x products remain compatible.

## 7. Trust Layer
v2.0 adds constitutional provenance and authenticity.
v1.x receipts remain valid.

## 8. Migration Steps
1. Update governance schema to include optional constitutional intent
2. Enable constitutional drift fields
3. Add constitutional provenance to receipts
4. Test constitutional bundles in runtime
5. Validate arbitration across domains

## 9. Conclusion
Codex OS v2.0 is fully backward-compatible with v1.x.
Migration is additive, not breaking.
