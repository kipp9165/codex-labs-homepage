# Affiliate FAQ

## How affiliates get paid

Affiliates do not need a Stripe account, linked bank, or technical setup. Payouts are manual and can be sent through Venmo, PayPal, Cash App, Zelle, bank transfer, or check.

## How referral links work

Each affiliate gets a unique referral link that uses a `?ref=NAME` query parameter, such as `?ref=jason`. The site stores that referral code in local storage so it can be preserved across later internal page visits.

## Offline promotion

Offline promotion is welcome. Affiliates can share their referral links through flyers, word of mouth, print materials, email, text, or direct messages as long as the final link includes the affiliate's `?ref=NAME` code.

## Current manual tracking process

Tracking is manual for now. Referral IDs and resulting purchases are reconciled in a spreadsheet or Baserow so attribution and payouts can be reviewed before payment is sent.
